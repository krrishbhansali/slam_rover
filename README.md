# Slam Rover workspace

ROS 2 Humble rover simulation with an RGB camera, 2D lidar, SLAM Toolbox and Nav2.

Source, build, launch instructions, and the six launch-file responsibilities are in
[src/slam_rover/README.md](src/slam_rover/README.md).

Build from this directory. The `build/`, `install/`, and `log/` directories are
generated locally and should not be committed. Include required source and asset
files when publishing this workspace.
